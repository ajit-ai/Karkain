# v1.2.23 — Memory Safety Phase 1 Baseline

**Status: COMPLETE (Go + kcc).** Increment v1.2.23: linear types + K160 on both engines,
Option/Result match completeness. No GC, no reference counting, no arena-region work,
no adaptive policy engine (those are v1.2.24+).

## 1. Pre-state (measured)

- `linear type Handle { id int }` parsed by Go; kcc could not parse `linear` at all
  (`expected variable name after type 'linear'`).
- Go borrow checker `checkLinearTypes` (whole-program, by name) never fired for
  `let h = Handle{id: 7}` because `inferMatchType` had no `StructLiteral` case, so
  `typeName` stayed `""` and the linear check skipped the binding. Verified:
  `lin_twice` and `lin_unused` printed `Check passed.` exit 0.
- `check` did NOT run the borrow checker at all (`pkg/cli/checker.go` has no
  borrow handling); only `build`/`run`/`dbg`/`lint`/`incremental` did. Gate
  diagnostics therefore route through `build`.
- Option/Result: exhaustive-match check existed (Go); kcc did not enforce it.
  Non-exhaustive Option match rejected on Go `build` only.

## 2. Changes

- Go (`pkg/sema/borrow_checker.go`): per-binding/per-scope linear tracking.
  `varEntry` gained `linear bool` + `uses int`. `declare` sets `linear` from
  `linearTypes[typeName]` and stores `line`. `trackUsage` increments the resolved
  binding's `uses`. `checkMove` increments `uses`. `checkVarDecl` passes
  `uint16(n.Line)` and `inferMatchType` gained a `StructLiteral` case returning
  `TypeName`. `StructLiteral` field-name identifiers no longer count as uses.
  `popScope` verifies `uses == 1` for linear bindings and emits K160. Removed the
  old whole-program `checkLinearTypes` pass. Fixed the column-0 `parent :=` lines.
- `pkg/diagnostics/codes.go`: added `CodeK160`.
- `pkg/cli/explain.go`: K160 entry.
- kcc (`src/compiler/lexer.kark`): `TK_LINEAR` (152) + keyword.
- kcc (`src/compiler/ast.kark`): `makeLinearTypeDecl` + accessors.
- kcc (`src/compiler/parser.kark`): top-level `linear type` dispatch.
- kcc (`src/compiler/checker.kark`): collect linear type names, register linear
  locals in `collectLocals`, count uses in `checkIdent` and `Move`, verify at
  function exit emitting K160. `StructLiteral` allows `linear` kind.
- `docs/source/reference/stable-api.rst`: K160 added to the code range.
- `.github/workflows/ci.yml`: new step `Run v1.2.23 memory safety Phase 1 gate`.
- `pkg/cli/phase_v1223_memsafety_test.go`: gate.
