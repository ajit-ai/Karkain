# v1.2.4 — native `trim`

## Summary
`trim(s)` is now lowered by the kcc self-hosted native driver as a
non-allocating view `(base+start, end-start+1)`, mirroring the Go oracle's
`emitTrimHelper` (pkg/native/program.go:3571) byte for byte. Whitespace set
matches both engines: space, tab, LF, CR.

## Implementation
- `src/compiler/native_value.kark`:
  - `natFrameLayout` gained a conditional `codecTemp` region (8*5 bytes) after
    `mapStage`, before `extrasBase`; slot indices shifted (codecTemp=4,
    extrasBase=5, next=6, frame=7). All consumers updated.
  - `natTrimHelper` ports the oracle's helper (frame 64, offsets ptr=0/end=8/
    start=16/argLen=24, label order trim$lead/leaddone/leadadv/tail/taildone/
    tailadv/final/empty).
  - `natEmitTrimCall` ports `emitStringCodec`'s five-unit staging at
    codecTemp.
  - Program-wide codec flag `natNativeProgramUsesCodec` (trim sites).
  - Helper emitted after the runtime-error reporter, matching oracle order.
  - Scan/refusal/decl/print integration; trim in return position refused.
- `natFrCodecTemp` accessor added.
