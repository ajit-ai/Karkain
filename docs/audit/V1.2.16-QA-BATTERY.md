## 3. Harness changes

`scripts/qa/run-full-qa.ps1`:

1. Header rewritten from `Karkain 1.2.0 master QA gate` to the v1.2.x/v1.2.16
   closeout, with a pointer to this audit note and an explicit warning that
   the script is the source of the battery, not a green claim.
2. Added a PATH prelude that prepends `C:\Program Files\Git\cmd`,
   `C:\Windows\System32\WindowsPowerShell\v1.0` and
   `C:\msys64\mingw64\bin` when they exist and are not already on `PATH`.
3. Replaced the single `cligates` stage with `cli114`, `cli115`, `cli116`,
   `cli117`, `cli118`, `cli119`, each anchored (`^TestPhaseNNN_`) and given
   its own timeout (30 min for the two-engine Phase-114 corpus, 20 min for the
   others). `conformance` and `probes` remain separate anchored stages.
   `-Stage cligates` now exits 2 with an explanatory message rather than
   silently doing nothing.
4. Fixed a pre-existing `Run-Stage` wrapper defect: `build` and `vet` were
   inside `if (-not $Stage)`, so `-Stage build` and `-Stage vet` reported
   `ALL STAGES GREEN` with an empty passed list. They are now called
   unconditionally and filtered by `Run-Stage` itself.
5. `units` gained an explicit 20-minute timeout so a bootstrap burn cannot
   occupy the runner indefinitely.
6. `ci.yml` follow-up on PR #37: the `native-macos` job now carries
   `if: github.event_name == 'push' && github.ref == 'refs/heads/main'`. On
   this PR the `pull_request` and `push` check runs both sat **Queued** without
   starting on the macOS runner, so they produced no evidence while holding
   the board. PR and `develop` runs now SKIP; the execution gate still runs on
   the canonical push to `main` after owner merge, and the structural Mach-O
   gates remain in the required `Test` job on every run. This is a scheduling
   condition only — gate file, `macos-13` runner, 25-minute timeout and
   exact-byte assertions are unchanged. The v1.2.15 record is updated in
   `docs/audit/V1.2.15-MACOS-EXECUTION.md` §4.
